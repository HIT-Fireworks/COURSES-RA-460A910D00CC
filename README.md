## 维护约定

- GitHub description 按稳定顺序展示尽可能多的完整代码→原始课程名条目。
- 超过 350 字时以“尚余 N 项”明确标记截断；不得在代码或课程名中间硬截断。
- 完整课程映射始终以本 README 与 Registry 为准。
- 文件库存、容量和内容分类属于 Registry 或审计索引，不写入 description。
- 普通内容增删不应触发 description 更新；课程代码成员或原始课程名变化时才更新。
- 资料归属必须遵守仓库路由与物理仓库契约。
